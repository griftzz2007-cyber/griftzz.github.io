# 🚀 Quick Start Guide

## Langkah Cepat untuk Memulai

### 1️⃣ Buka Website
```
Double-click file: portofolioTugas.html
```
Atau drag & drop file HTML ke browser Chrome/Firefox/Edge.

---

## 2️⃣ Fitur yang Bisa Langsung Dicoba

### ✅ Navigasi Smooth
Klik menu di atas:
- **Beranda** → Scroll smooth ke beranda
- **Profil** → Scroll smooth ke profil  
- **Proyek & Keahlian** → Scroll smooth ke proyek
- **Kontak** → Scroll smooth ke kontak

### ✅ Dark Mode
Klik tombol **🌓** di pojok kanan atas untuk toggle dark/light mode.

### ✅ Back to Top
Scroll ke bawah, klik tombol **↑** untuk kembali ke atas.

### ✅ Mobile Menu
Resize browser ke ukuran mobile atau buka di HP, klik **hamburger icon** (☰) untuk menu.

---

## 3️⃣ Animasi Otomatis

### Yang Berjalan Otomatis:
- ✨ **Typing Effect** di header (tunggu 1 detik)
- ✨ **Fade-in Animations** saat scroll
- ✨ **Progress Bars** di section keahlian
- ✨ **Scroll Progress Bar** di atas halaman
- ✨ **Parallax Effect** pada profile image

---

## 4️⃣ Customization (Optional)

### Ganti Foto Profil
1. Siapkan foto Anda (format: JPG/PNG)
2. Rename menjadi `profile.jpeg`
3. Replace file di folder `images/`

### Ganti Warna Tema
Edit `style.css`, cari dan ganti:
```css
#0056b3  →  warna favorit Anda
```

### Ganti Konten
Edit `portofolioTugas.html`:
- Nama, NIM, data diri
- Skill list
- Project descriptions
- Contact info

---

## ❓ Troubleshooting

### Masalah: Tidak ada animasi
**Solusi:** Refresh halaman (F5) atau clear cache (Ctrl+Shift+R)

### Masalah: Dark mode tidak save
**Solusi:** Pastikan browser mengizinkan localStorage

### Masalah: Menu mobile tidak muncul
**Solusi:** Resize browser width < 768px
