# Website Modern dengan Tailwind CSS

Website portfolio modern yang dibangun menggunakan Tailwind CSS.

## Fitur

- ✨ Desain modern dan responsif
- 🎨 Gradien warna yang menarik
- 📱 Mobile-friendly dengan menu responsif
- 🚀 Animasi dan transisi yang smooth
- 💼 Portfolio showcase
- 📧 Form kontak
- 🔗 Social media links

## Teknologi yang Digunakan

- HTML5
- Tailwind CSS (via CDN)
- JavaScript Vanilla

## Cara Menggunakan

1. Buka file `index.html` di browser
2. Atau gunakan live server untuk development

## Sections

1. **Hero** - Bagian pembuka dengan CTA buttons
2. **About** - Informasi tentang diri dan statistik
3. **Services** - Layanan yang ditawarkan (6 layanan)
4. **Portfolio** - Showcase project (6 project)
5. **Contact** - Form kontak dan informasi kontak
6. **Footer** - Newsletter dan quick links

## Customization

Untuk mengubah warna tema, edit bagian `tailwind.config` di dalam tag `<script>`:

```javascript
tailwind.config = {
    theme: {
        extend: {
            colors: {
                primary: '#3b82f6',    // Ubah warna primary
                secondary: '#8b5cf6',  // Ubah warna secondary
            }
        }
    }
}
```
